A modern, responsive WordPress theme for Tanta Scan medical center using Bootstrap 5, converted from original Tailwind HTML template.

== Description ===

This theme is designed specifically for the Tanta Scan medical center website. It features:
- Full responsiveness using Bootstrap 5
- Right-to-left (RTL) language support for Arabic
- Modern design with medical center branding
- Customizable header and footer
- Multiple page templates
- Widget-ready sidebar
- Translation ready

The theme includes:
- Custom header with hospital logo and navigation
- Hero section with call-to-action
- About section
- Services section with medical imaging units
- Footer with contact information, social media links, and gallery

== Installation ==

1. Upload the `tanta-scan-bootstrap` folder to the `/wp-content/themes/` directory
2. Activate the theme through the 'Appearance' menu in WordPress
3. Customize the theme using the WordPress Customizer
4. Set up your menus and widgets as desired

== Frequently Asked Questions ==

= How do I change the colors? =
The theme uses CSS variables for easy color customization. Edit the :root section in css/custom.css to change the primary, secondary, and accent colors.

= Is this theme compatible with page builders? =
Yes, this theme is compatible with popular page builders like Elementor, Beaver Builder, and Gutenberg.
